# LaserGround Planner
Учебный FastAPI-проект для мониторинга наземных лазерных терминалов связи.
В финальном виде сервис будет хранить терминалы, пользователей, роли и оптоволоконные связи.
Приложение будет получать погодные данные, рассчитывать доступность терминалов и объяснять результат.
Если исходный терминал недоступен, система подберёт доступный терминал и маршрут по fiber-сети.
Backend строится на FastAPI, SQLAlchemy, PostgreSQL, Alembic и JWT-авторизации.
Для демонстрации планируется простой веб-интерфейс с Leaflet-картой и страницей планирования передачи.
